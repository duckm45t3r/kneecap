## What it is

Desktop IC copilot (Tauri 2 + React 19 + Rust). URL / pasted text / PDF →
screening memo or full IC report. Runs against a BYO key, a local Ollama model,
or the VHS-hosted model. **All user data (memos, decks, keys) lives locally on
the user's machine — nothing is stored in the cloud.**

## Storage model — local-first, deal/version (2026-06-25)

- A saved report is a **deal** that evolves: **deal → versions (流水號 v1/v2…) →
  accumulated sources**. A new version re-generates the full report from ALL
  accumulated sources (deck → + data room → + supplements).
- Stored in **local SQLite `kneecap.db`** at
  `~/Library/Application Support/capital.vhs.kneecap/` (`deal` / `source` /
  `version` tables). Old flat `reports/*.json` migrate to deals (v1) on first run.
- Storage is identical for BYO and hosted. The cloud is involved ONLY as a
  seconds-long transit buffer for big hosted PDFs (see below), never for storage.

## LLM providers & PDF reading

| Provider | PDF mode | Reads image/scanned PDF? |
|---|---|---|
| VHS-hosted (Claude Sonnet 4.6) | native vision | ✅ |
| Anthropic BYO | native vision | ✅ |
| Gemini BYO | native vision (inline_data) | ✅ |
| OpenAI BYO (gpt-4o, file part) | native | ⚠️ **UNVERIFIED** |
| Nvidia / Nemotron `nvidia/llama-3.3-nemotron-super-49b-v1` | extracted text only | ❌ image PDFs |
| Local Ollama | extracted text only | ❌ image PDFs |

Vision providers "see" the page images; text-only models rely on local text
extraction, which yields ~nothing for image/scanned decks.

  source × 5 sections; the 5× resend is a pending caching optimization.

## Hosted PDF transport — the Vercel limit & the presigned path

The hosted proxy is a Vercel serverless route capped at **~4.5MB request body**.

- **Small PDFs → inline:** base64 in the body, bounded by a running budget (<4MB total).
- **Big PDFs / data rooms → presigned:** the desktop uploads each oversized PDF
  out-of-band via a server-issued presigned PUT to **Supabase Storage** (private
  bucket `kneecap-dealroom`, S3-compatible, env `STORAGE_S3_*`). `/generate`
  receives object refs; the proxy fetches each PRIVATE blob server-side → base64 →
  native document block → Anthropic → **deletes after** (all reject paths covered;
  Supabase has no native TTL). Confidential decks are never network-reachable (no
  presigned GET; user-scoped keys `u/<userId>/<uuid>.pdf` + ownership check).
  Caps: 25MB/PDF, 30MB aggregate, 10 PDFs.
- **BYO has NO Vercel limit** (desktop → provider directly) → handles full data
  rooms up to Anthropic's 32MB / 100-page request limit.
